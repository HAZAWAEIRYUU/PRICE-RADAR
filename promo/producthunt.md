## Description
Price-Radar is a competitor price monitoring dashboard built for e-commerce sellers in Japan.

### The Problem
E-commerce sellers spend 30+ minutes every day manually checking competitor prices across Amazon, Rakuten, and Yahoo Shopping. By the time they notice a competitor's price drop, they've already lost sales.

### The Solution
Price-Radar automatically monitors competitor prices every hour and alerts you when competitors undercut your prices. See everything in one dashboard.

### Key Features
- Real-time price monitoring across Amazon.co.jp, Rakuten, Yahoo Shopping
- Instant price alerts when competitors go lower
- Price history charts to spot trends
- Free plan: 3 products, forever free
- Pro plan: 50 products for just $13/month

### Built With
- Frontend: Next.js + Tailwind CSS (hosted on Cloudflare Pages)
- Backend: Python FastAPI (hosted on Render)
- Database: PostgreSQL (Supabase)
- Payments: Stripe
